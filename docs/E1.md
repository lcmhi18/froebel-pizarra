## Limitaciones y riesgos registrados

- `compatibility_date=2026-10-26` se mantiene porque es la fecha máxima que admite el runtime de Wrangler 4.152 instalado. No se actualizó Wrangler fuera de la versión pedida.
- `RETENTION_HOURS=24` queda configurado, pero la purga por alarmas y los límites nuevos se implementarán en E2/E3; no se presentan como terminados.
- El Registry sigue usando la identidad anterior `singleton`. Su cambio a `registry` debe diseñarse en E2 preservando compatibilidad con las salas previas.
- La configuración externa de app/ no equivale a haber verificado su build real. Cuando lleguen sus archivos, el proceso se detendrá si resuelve React/React DOM distintos de 18.3.1. No se instala ni modifica app/ para forzarlo.
- npm audit notificó cuatro entradas de severidad alta, derivadas de picomatch <=4.0.7 en las herramientas de build (Vite/fdir/tinyglobby). El registro npm consultado todavía solo ofrecía hasta picomatch 4.0.7; 4.0.8 devuelve 404. No se inventó una versión ni se aceptó el downgrade de Vite sugerido por npm. Es una dependencia de desarrollo, no un módulo del Worker publicado. Queda registrada para revisar cuando haya corrección compatible, antes de la publicación final.
- Vite muestra dos avisos de build sobre directivas use client de React Router. La compilación y las pruebas de consola del navegador pasan. No se ocultaron los avisos.
- La nueva especificación completa, las nueve pizarras reales y el wrapper Konva no están implementados por E1.
