# Matriz de equivalencia de geometría — base para E10

E9 incorporó el código del HTML y comprobó recorridos representativos. «Incorporado» no significa que cada combinación esté certificada. E10 debe completar el detalle por botón y gesto a partir del archivo original, sin sustituir esa comprobación por esta lista de familias.

| Familia o recorrido | Incorporado en E9 | Comprobación pendiente en E10 |
| --- | --- | --- |
| Triángulos | Seis construcciones, vértices, clasificación, grados, exteriores, divisiones, marcas, giro/escala | Cada construcción, gesto y opción en modo personal y compartido |
| Cuadriláteros | Nueve construcciones, diagonales, paralelas, medidas, rellenos | Todas las variantes y sus transformaciones |
| Círculo | Radios, elementos, colores por elemento, sectores, cuerdas, tangente/secante, medidas y desarrollo | Cada elemento, pintura y combinación de ángulos |
| Áreas | Modelos, elementos, comprobación y fórmulas | Todas las figuras y etiquetas/medidas |
| Poliedros | Diez opciones de creación incluyendo sorpresa; caras, aristas, vértices, Euler, desarrollos | Cada sólido y cada color, vista y tipo de desarrollo |
| Cuerpos | Cilindro, cono, esfera, elementos y desarrollo/revolución | Todos los controles y reproducción/inversión |
| Ángulos | Ángulos predefinidos/sorpresa, extremos, bisectriz y transportador | Valores, arrastre, límites y medidas |
| Líneas | Recta, rayo, segmento, familias de rectas y transversal | Construcciones, puntas, nombres, rotación, colores |
| Dibujo | Lápiz, línea, texto con símbolos/potencias y figuras básicas | Entradas especiales, trazos largos y edición de cada figura |
| Galería | 51 entradas, filtros, selección, zoom e inserción | Cada tarjeta, imagen y combinación de inserciones |
| Pintura | Balde, quitar color, regiones y colores de objetos | Regiones pequeñas, intersecciones y deshacer |
| Acciones | Copiar, borrar, limpiar, giro, escala, imán, vista grande y ocultar opciones | Atajos y gestos, estado tras cambio de selección |
| Clase | Crear/aceptar, estado compartido, lectura, navegación y deshacer por usuario | Todos los recorridos de sala con estados geométricos complejos |
| Visual y accesibilidad | Diseño azul/blanco/amarillo y logo reutilizado, móvil con desplazamiento interno | Iconos/ilustración frente a referencia, foco, etiquetas secundarias y táctil |
| Robustez | Saneado HTML/SVG, mensajes acotados y estados inmutables | Estados malformados, relojes distintos, desconexión durante gesto/animación y rendimiento |

E7 Konva sigue separado y pendiente; esta matriz se refiere únicamente al HTML SVG de geometría enviado por el usuario.
