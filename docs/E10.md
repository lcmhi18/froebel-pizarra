# E10 — equivalencia y robustez de geometría

La pizarra SVG del HTML del usuario tiene una comparación reproducible con su original y recorridos verificados en navegador. Esta etapa se entrega localmente; no publica cambios ni modifica `app/`. Konva conserva el resultado del spike E7.

## Cambios y fallos corregidos

- Los deslizadores conservan su elemento y foco durante la edición; el redibujado del estado ya no reconstruye el control activo.
- Las tarjetas de la galería admiten Enter/Espacio y mantienen sus etiquetas y acceso por teclado después de seleccionar o ampliar. Los colores y parámetros tienen nombres accesibles.
- Se validan las figuras antes de dibujarlas o buscarlas para interacción. Una figura incompatible permanece en el estado compartido y se omite visualmente; no borra las otras. Los errores de un objeto se aíslan del resto del dibujo.
- Transportadores y comandos de animación malformados se representan con valores seguros, sin bucles infinitos. Se corrigió un límite que confundía los timestamps de época de animaciones legítimas con coordenadas y ocultaba el círculo al reproducirlo.
- No se cambia el protocolo, sus cuotas, el motor genérico ni el servicio de autenticación.

## Pruebas reproducibles

`npm run test:e10` construye la aplicación y ejecuta las 94 pruebas previas, la simulación de profesor/seis alumnos y 150 pruebas nuevas: **244 pruebas**, además de la simulación. `npm run test:equivalence` ejecuta solo las 150 nuevas.

`tests/e10/original-geometry.fixture.js` conserva el código matemático de referencia del HTML con las cinco imágenes convertidas a rutas locales y sin el antiguo servicio de clase. Es una referencia offline para Node VM, no código del frontend. El harness usa un DOM simulado, sin navegador ni red. Compara datos y SVG exactos, normalizando únicamente los IDs y la envoltura que identifica objetos compartidos. Esto permite repetir las pruebas sin depender de Downloads.

## Probado / no probado / limitaciones conocidas

| Estado | Alcance |
| --- | --- |
| Probado | Los casos y recorridos anteriores, compilación, tipos, protocolo y simulación local. |
| No probado | Dispositivos táctiles físicos, Safari/Firefox, login Supabase real, despliegue de producción, miles de aulas y todas las combinaciones de pintura/intersecciones/gestos. No se certifica equivalencia exhaustiva por combinar cada opción con todas las demás. |
| Límite visual | La composición, marca y colores siguen la referencia; el búho e iconos 3D de la imagen no están reproducidos. No es una copia pixel por pixel. |
| Límite de red | 64 KiB por mensaje y 1 MiB de estado. Una pizarra excesiva puede alcanzar las cuotas. Las animaciones dependen del reloj del dispositivo; no se garantiza sincronía de fotogramas entre relojes desajustados. |
| Antes de publicar | Resolver la revisión de objetos históricos cerrados documentada en E3 y revisar orígenes permitidos. Konva no está integrado; ver E7. |

No se activaron servicios de pago, narración externa, push ni despliegue. Cloudflare mantiene la verificación de correo/cuenta autorizados mediante `npm run worker:deploy`.

Dos objetos antes de deshacer; cero errores/avisos capturados. Evidencia adicional: `.e10-test/geometria-final.jpg`; log completo de test:e10: `.e10-test/verification.log`. El build conserva los avisos conocidos de directivas de React Router y del cambio de nombre del paquete de pruebas de Cloudflare; no hubo fallos.
