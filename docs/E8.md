# E8 — Verificación final local

## Historia verificada

El profesor crea una sala, el alumno solicita acceso y espera; al aceptarlo, ambos editan la página SVG. La UI se conecta por HTTP/WebSocket al Worker, que aplica permisos y persiste en SQLite. Los snapshots y operaciones confirmadas regresan a ambos editores. Cambiar de pizarra navega a otra página y conserva el contenido de cada una. El cierre deja los editores en solo lectura.

## Automatización

Se añadió scripts/sim.ts y npm run test:sim. Ejecuta un Worker local aislado en 8791 y simula un profesor y seis alumnos con WebSockets reales; no abre una cuenta ni llama a servicios remotos. Comprueba privacidad del pendiente, permisos, cinco activos y ROOM_FULL para el sexto, rechazo (4003), expulsión (4001), reentrada de ambos, pausa, retorno del profesor, cambios entre dos pizarras, conservación del objeto original y cierre de toda la clase (4002). Los clientes y servidor se cierran al terminar; los datos de prueba quedan ignorados en .e8-test/.

npm run test:e8 agrupa build + engine + navegación + transporte + Worker + scaffold + simulación. En la primera ejecución de esta entrega pasaron las 85 pruebas existentes; la simulación falló por dos expectativas de códigos invertidas en el script nuevo. Se corrigieron las expectativas según el protocolo vigente, sin cambiar el servidor, y npm run test:sim pasó completo después. Después se repitió npm run test:e8 de principio a fin: terminó con código 0, las 85 pruebas y la simulación correctas. El primer fallo queda documentado como una expectativa incorrecta del script nuevo.

## No probado y limitaciones conocidas

| Área | Estado |
| --- | --- |
| Login real y autorización Supabase en producción | No probado en E8; la creación de la sala de navegador usa bypass exclusivamente local. |
| Producción/Vercel/Cloudflare remoto | No desplegado ni validado por esta entrega. |
| Migración histórica | Pruebas locales existentes pasan; los objetos remotos cerrados que no despiertan siguen necesitando revisión antes de publicar, según E3. |
| Konva /app-live | E7 documentado; no integrado. No se cambió la candidata externa ni app/. |
| HTML completo de geometría | Pendiente E9/E10; las dos pizarras actuales son de prueba. |
| Miles de aulas y dispositivos físicos modestos | Sin prueba de carga ni validación física. El presupuesto de diff es una medición unitaria, no de capacidad de servicio. |
| Accesibilidad con lector externo | No probado; se utilizaron árbol accesible y controles por nombre del navegador. |
| Automatización del arrastre | CUA emitió un error de comprobación de shadow root al terminar el gesto, pero el movimiento se aplicó. Se verificaron después los transforms iguales y distintos del inicial en ambos DOM, y su restauración con Deshacer. No se afirma ejecución del gesto sin incidencia del controlador. |
| Avisos de herramientas | Vite avisa sobre use client de React Router; el pool de Cloudflare avisa de su nuevo nombre; Wrangler anuncia una actualización disponible. No son avisos de consola de la página ni fallos de esta compilación. No se actualizaron dependencias. |
