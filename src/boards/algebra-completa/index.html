Elige un tema, escribe cualquier ejercicio y la ranita lo explica paso a paso.

Toca “⬆️ Escribir arriba” para escribir el exponente y “⬇️ Escribir abajo” para volver a escribir normal. En el teclado de tu laptop: flecha ↑ = exponente, flecha ↓ = normal. Para multiplicar usa ×. Para una fracción toca “➗ Fracción” y usa Tab para pasar del numerador al denominador.

📒 Fórmulas

La fórmula del tema que estás usando se ilumina. Arrastra una tarjeta (✋) hasta la pizarra y se queda ahí; muévela o quítala con ✕.
